# 大模型 API 价格

**在线访问：https://pricing.pddshop.cc/**

一个静态页面，分**文本 / 图片 / 视频 / 语音**四类列出主流厂商最新模型的 API 价格（美元），支持搜索、按厂商筛选、点表头排序。

| 大类 | 价格列 |
| --- | --- |
| 文本 | 输入、缓存输入、输出（/ 百万 tokens） |
| 图片 | 每张（按张计费的模型）；输入、图片输出（按 token 计费的模型，/ 百万 tokens） |
| 视频 | 每秒起价、10 秒视频起价 |
| 语音 | 类型（合成 / 识别）；按量价格（合成多为 / 百万字符，识别多为 / 分钟）；输入、输出（按 token 计费的模型） |

## 全自动收录，无需维护

项目设计成无人维护也能长期跟上各厂商的产品变化。不维护任何型号名单。

**1. 产品线（挡位）**：同一厂商的模型按"去掉版本号后的名字"归为一条产品线，例如 GPT-5.6 Luna、GPT-6 Luna → `gpt luna`。每条产品线只展示最新版本。各挡位更新节奏不同也没关系：Terra 升到 6.1、Luna 还停在 6 时，两者都显示各自的最新版。

**2. 哪些挡位算主流——看真实使用量**：同步脚本读取 OpenRouter 各厂商页面上近几天每个模型的使用量，按产品线汇总（同一挡位的历代版本、`~xxx-latest` 别名都算进去）：

| 大类 | 入选条件 |
| --- | --- |
| 文本 | 在该厂商文本模型中花费占比或 token 占比 ≥ 5%（旗舰挡位花费高、便宜挡位 token 多，两者任一达标即可），每家最多 8 条 |
| 图片 / 视频 | 请求数占比 ≥ 10%，每家最多 3 条 |
| 语音 | 合成、识别分开算，请求数占比 ≥ 10%，每家每类最多 2 条 |

由此自动处理：
- **厂商改名**（如 GPT-5.4 Mini → GPT-6 Luna）：新名字使用量上来后入选，旧名字使用量掉下去后淘汰；
- **新产品线刚发布**还没有使用量：发布 30 天内直接收录；
- **老型号**：超过 540 天的不再展示；
- 结果写进 `models.json` 的 `tiers`，页面实时数据只负责"每个挡位的最新版本和价格"。

**3. 厂商**：内置一份常见厂商名单；此外 OpenRouter 本周排行榜上出现的正式付费文本模型的厂商会被自动收录（写进 `vendors`），掉出榜单 30 天后移除。

**4. 数据刷新**：
- 页面打开时先显示 `models.json` 快照，同时浏览器直接请求 OpenRouter 公开目录，用实时价格替换（文本、图片、语音）。
- 视频价格只写在各模型页面上，由同步脚本抓取。
- GitHub Actions 每 6 小时运行一次：先跑测试，再同步，最后提交 `models.json`，Vercel 随之自动部署。

**5. 出错时**：厂商页面、排行榜、视频页面读取失败都会沿用上次结果，并在 Actions 运行页面显示黄色警告；某个大类数量骤降或厂商整体消失时该大类沿用旧快照。`tests/select.test.mjs` 用虚构数据模拟了改名、挡位停更、新厂商等情况。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面（样式和脚本都在里面） |
| `select.js` | 挑选主流模型的规则，页面和同步脚本共用 |
| `models.json` | 数据快照 |
| `scripts/sync.mjs` | 刷新快照：读取使用量、计算主流挡位、发现新厂商、抓取视频价格 |
| `scripts/serve.mjs` | 本地预览服务器 |
| `tests/select.test.mjs` | 挑选规则的场景测试 |

想调整收录尺度，改 `select.js` 里 `CATEGORIES` 各大类的 `threshold`（占比门槛）和 `perProvider`（每家上限）。

## 本地运行

零依赖，只需 Node 20+：

```bash
npm test       # 场景测试
npm run sync   # 刷新快照
npm run dev    # 打开 http://localhost:3000
```

## 部署

部署在 Vercel，推送到 `main` 即自动上线；`vercel.json` 已声明为纯静态站点、无需构建。定时任务更新 `models.json` 后也会触发重新部署。

换到 GitHub Pages、Cloudflare Pages 等任意静态托管同样可用。

## 说明

价格来自 OpenRouter 的路由报价，可能与厂商直连价格、国内人民币价格、批量或阶梯优惠不同，以官方账单为准。
