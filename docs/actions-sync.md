# 模型同步故障与维护

## 2026-09-08：OpenAI 对比页默认模型变化

失败任务： https://github.com/billowssun/API-pricing/actions/runs/34170195096

旧解析器从 `/api/docs/models/compare` 搜索每个模型名称，再向后截取 1800 个字符。对比页只展示默认选择的模型，不是完整目录。默认选择变化后，GPT-5.6 Luna 不再出现，脚本因此退出；这不代表模型下架。此外，导航中的名称和相邻卡片还可能导致串价。

修复后按 API ID 读取独立官方模型页，校验页面标题、每百万 token 单位及完整的标准文本价格字段。无法确认时保留上次数据并使任务失败，不把旧价格标记为刚验证，也不以聚合报价冒充官方价格。curl 回退现在拒绝 HTTP 错误响应。

## 防止复发

- `npm test` 覆盖对比页换卡片、导航串价、字段缺失、单位变化、请求失败及原始数据不被修改。
- PR 与 main 推送运行 `npm run check`（测试、数据校验、类型检查和构建）；定时同步另外验证真实外部页面。
- 任务摘要和 `pricing-sync-status` artifact 保留具体失败来源及 URL。外站改变结构仍可能触发失败：这是保护数据准确性的报警，不应通过吞掉异常消除红灯。
- 在 GitHub 的仓库通知中订阅 Actions 失败；建议把 `validate` 配置为 main 分支的必需检查。仓库保护规则和个人通知设置未由本次修复更改。

## 下次出现红灯时

1. 查看失败步骤及任务摘要；从 artifact 下载 `sync-status.json`，确认检查时间，避免把历史文件当成本次结果。
2. HTTP 429/5xx 可重跑；404/标题不匹配需核对官方独立模型页及弃用公告，不能仅凭列表缺失自动下架。
3. 字段或单位变化：更新解析器和对应测试，运行 `npm run check`。
4. 在修复分支手动运行“同步模型价格”；非 main 分支不会提交价格到 main。真实同步与构建通过后再合并。

本地命令使用 Node.js 22，与 Actions 保持一致。第三方页面可访问性检查不等于该厂商所有价格已经重新抓取；只有成功解析的价格才能推进各模型的 `lastVerifiedAt`。
